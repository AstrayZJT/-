# 演示视频脚本（3–5 分钟）

录制建议：1920×1080，浏览器 100% 缩放，关闭无关通知；提前执行 `scripts/reset.ps1`，按顺序操作，避免临场等待。

| 时间 | 画面 | 操作 | 旁白要点 |
|---|---|---|---|
| 0:00–0:20 | 登录页 | 展示品牌与功能列表 | "这是我们做的社交网络原型 SocialSim，包含平台、水军模拟、内容审核和攻防实验室四个部分。" |
| 0:20–0:50 | 信息流 | 用 `linxiaoyu` 登录，发一条图文，点赞、评论 | "先看普通用户：发帖、信息流、互动都是完整可用的。" |
| 0:50–1:30 | 水军模拟 | 管理员登录 → 水军模拟 → 20 个 BOT、点赞+评论、30 秒 → 启动 | "水军任务支持批量建号、动作编排；这里 20 个账号同时刷一条帖子。" |
| 1:30–1:50 | 任务详情 | 打开任务曲线，说明执行次数 | "后台能看到执行次数随时间上升，这就是刷屏曲线。" |
| 1:50–2:30 | 审核队列 | 打开待审，展示文本/图片/视频理由与分数，通过一条、驳回一条 | "审核侧给出模态、标签、置信度和理由，人工做最终处置。" |
| 2:30–3:10 | 攻防实验室·文本 | 输入广告文案 → 运行 → 看三列结果与变体表 | "关键词基线被同音字绕过；归一化后拦住；模型兜住 Emoji 改写。" |
| 3:10–3:35 | 攻防实验室·图片 | 加载示例广告图 → 生成对抗样本 | "PGD 扰动后，人眼几乎看不出变化，分类器却判成了正常。" |
| 3:35–3:55 | 攻防实验室·视频 | 分析演示视频，对比 1fps 与 0.4s | "广告只出现 0.3 秒，1fps 正好跨过；密采样才能抓到。" |
| 3:55–4:25 | 防御设置 | 等级 0 → 2，保存；回实验室重跑文本 | "把防御等级调到 2，再跑同样的攻击，绕过率明显下降。" |
| 4:25–4:45 | 运营看板 | 展示统计、绕过率柱状图、审核分布 | "所有实验数据都进了看板，报告里的数字就是这里来的。" |
| 4:45–5:00 | 结尾 | 停在 README 或架构图 | "平台是载体，攻防对比是重点；全部代码和数据都在仓库里。" |

## 录制清单

- [ ] 分辨率 1920×1080，页面缩放 100%
- [ ] 提前 `scripts/reset.ps1`，确认待审队列非空
- [ ] 提前构建前端，确认 `http://127.0.0.1:8000` 可开
- [ ] 关闭 DevTools 与无关窗口
- [ ] 先彩排一遍，确认视频能播放、图片示例存在
- [ ] 录屏软件麦克风试音，语速稍慢
- [ ] 导出 mp4（H.264），文件名为 `SocialSim-演示.mp4`

## 备用方案

若现场网络/模型异常：直接播放预录视频；浏览器保持已登录状态；实验数据以 `ml/weights/*_metrics.json` 为准。
